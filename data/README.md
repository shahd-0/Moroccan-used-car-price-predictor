# Data

The dataset is not stored in this repository.

1. Download the **Moroccan Used Cars Dataset (MUCars, 2024)** from Mendeley Data or Kaggle.
2. Save the file as `cars_dataframe.csv` in this folder.

Expected columns: Brand, Model, Year, Condition, Mileage, Gearbox, Fiscal Power, Fuel, Equipment,
Number of Doors, Origin, First Owner, Location, Sector, Price (101,896 rows).
